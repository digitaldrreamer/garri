Everything on this page is turned into a PDF by your browser alone — no server, no second Chromium, nothing rasterised that has a vector equivalent.

How it works

The browser has already laid this page out. Rather than reimplementing that work, the renderer reads the answers back — line boxes, baselines, and the browser's own fragmentation — and writes them into a PDF. Text stays selectable, fonts are embedded and subset, and links like this one become real PDF annotations.

Page breaks come from Chromium itself, via a multicolumn container whose column height equals the page content height. CSS Fragmentation defines page boxes and column boxes as the same kind of container, so the answer is the one the print path would have given.

Colour, gradients and shadow

Backgrounds are filled paths; gradients become native PDF shadings rather than images; the shadow is rasterised, which is what Chromium's own export does too.

Borders and blend modes

Each border side is a mitred trapezoid, so non-uniform borders work. Dash geometry is derived from Chromium's own output: the dash is constant and the gap stretches to fit the side exactly.

A table whose header repeats

This table is long enough to cross a page boundary. Its header is furniture, not flow: it is re-issued on every continuation page, and its height is reserved so the rows below still land where Chromium puts them.
